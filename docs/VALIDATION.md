# 검증 기록

이 문서는 구현한 코드의 검사 범위를 기록한다. 사용자 조사나 실제 여행 성능을 의미하지 않는다.

검증 결과: Python 테스트 36개와 JavaScript 테스트 4개 통과. 선택형 FastAPI 실행 테스트 1개는 의존성 미설치로 건너뛰었다.

## 실행한 검사

| 대상 | 확인한 동작 |
| --- | --- |
| Python 일정 엔진 | 거리 상한·연속 보행·예산·계단·운영·식사·예약, 선호 충돌·미응답·미확인·필수 경험 |
| SQLite·API 서비스 | 저장과 재조회·토큰 해시·잘못된 토큰 차단·revision 충돌·확정 재검사·완료 구간 유지·삭제 |
| 로컬 HTTP | JSON 응답·요청 오류·API 비교·HTML 제공·디렉터리 목록 차단 |
| Python/JavaScript 일치 | 공통 23개 계획 입력과 3개 남은 구간 수정 입력의 전체 결과 비교 |
| 프런트엔드 상태 | 6단계 렌더링, 두 분 확인 전 확정 차단, 수정 버전 공유, 선택 변경 시 확정 초기화, 출력 문자열 이스케이프 |
| UI와 실제 Python 서비스 | 저장·확정·남은 구간 변경·삭제, 서버 요청에 사진과 카드 기록이 없는지 확인 |
| 소스 검사 | JavaScript 구문 검사·Python 컴파일 검사·정적 파일 연결 |

## 검증의 한계

프런트엔드 상태 검사는 DOM 대체 객체를 사용하며 실제 브라우저 렌더링 검사는 아니다. 이 환경에서 제공되는 브라우저 검증 경로를 사용할 수 없어 실제 화면의 시각 검사·파일 선택·인쇄·PNG 다운로드는 검증하지 못했다. 관련 기능은 구현 코드 상태로 구분한다.

선택형 FastAPI/httpx 의존성을 설치할 수 없어 FastAPI 어댑터의 실행 테스트는 건너뛰었다. 기본 Python 서버와 공유하는 서비스·저장·검사 엔진은 테스트했다. 의존성을 설치한 환경에서는 선택형 테스트를 실행할 수 있다.

거리·시간·비용은 가상 값이다. 실제 시설 접근성, 지도 거리, 운영시간, AI 응답 품질, 실제 가족의 선택·조율 시간은 검증하지 않았다.

## 재실행

```bash
python -m unittest discover -s tests -p "test_*.py" -v
node --test tests/*.test.js
node --check web/app.js
node --check web/planner.js
python -m compileall -q backend
python scripts/check_public.py
```

선택 의존성은 `requirements-dev.txt`에 있다. 테스트에서 임시 데이터베이스와 가상 역할을 사용하며 실사용자 자료를 쓰지 않는다.
